# Lecture 18 - Link Layer (Continued)

## Overview

With the last lecture, we have now firmly pivoted into the Link Layer (Layer 2).  We continued our discussion with regards to how a link (or channel) is split up examining different sorts of access mechanisms (FDMA, CDMA).  We discussed how random access to a channel would work (ALOHA, CSMA) and the notion of an exponential backoff (ex. pick up more dice each round on a collision / usage).

In today's lecture, we will first begin with a discussion of the coding project and then we will continue on the link layer content, looking at how a switch self-learns where different hardware (MAC) addresses can be found.  We will continue that discussion looking at various Layer 2 protocols including STP, VLAN, and various others as time allows.
