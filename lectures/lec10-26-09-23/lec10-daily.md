# Lecture 10 - Data Plane - Part 1

## Overview

At the start of the lecture, we will do a brief recap about QUIC as well as quick review of what we learned from the transport layer.  We will then discuss Coding Project 1, examining the server code and a pcap example. From there, we will then pivot into the Data Plane with a focus on the Network Layer (Layer 3) and specifically forwarding, the act of sending packets onto their destination.  This is in contrast to the Control Plane which governs the protocols on how the forwarding information is distributed / populated.
