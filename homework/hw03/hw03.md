# Homework 3 - Fall 26 - CSE 30264 - Computer Networks

Homework is to be completed individually. See [Homework 1](../hw01/hw01.md) for additional information.

In this homework, you will be writing two simple clients, one using the preferred mechanism for HTTP requests and the other writing a more generic version using normal TCP sockets.  Each of the parts will be written in Python.

## Preliminary - Remote Server Browsing

URL: http://ns-mn1.cse.nd.edu/iplog/hw3.html

Start Wireshark on your Wi-Fi adapter and do one of the following:

* Open the URL in your web browser and examine the raw source
* Run curl via the terminal or command prompt to the same URL

Stop the Wireshark capture and save the capture for your reference.  You may wish to use the filtering to reduce it only the particular server in question.

## Part 1 - Python Requests Library

Use the Python `requests` library to fetch the web page.  The [requests](https://pypi.org/project/requests/) package information can be found [here](https://pypi.org/project/requests/).

Output what comes back from the server to the console.  Ideally, this should just be the web page itself similar to what `curl` gives you and the `requests` library is well set up with various API calls to help you out.

## Part 2 - Simple TCP Socket

Using a generic TCP socket, connect to the web server (port 80) and request the content.  You may wish to use the Wireshark capture from the first part to help assist you with regards to the request payload.

Use [Beej's Guide](https://beej.us/guide/bgnet0/html/split/introducing-the-sockets-api.html) as well as this guide from [Real Python](https://realpython.com/python-sockets/) to help out.  You will be writing only the *client* side, the server is running the `ns-mn1.cse.nd.edu` machine on port 80.

Think about what you need to send and take a bit of inspiration from what you record using Wireshark when you do Part 1 (or the example pcap from Homework 2). You really don't need many headers at all, keep it simple, think about what you are getting from the server.

Same as above, output what comes back from the server to the console.  In this case, you will get everything from the server.  You do not need to distinguish the resulting status code, just output everything you get back to the console.
