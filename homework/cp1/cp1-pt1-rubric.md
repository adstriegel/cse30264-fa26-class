   * 1 pt - Shell script

   * 1 pt - INFO / INFO-RESP appears to work correctly
   * 4 pts - All ASCII readable files work
   * 6 pts - All binary files work correctly
* [6 pts] - Shell script - `batchgrab`
   * 1 pt - Code runs without errors
   * 2.5 pts - All robust ASCII sets (Set 1-3)
   * 1 pt - Binary set (Set 5)
   * 1.5 pt - Error set (Set 4)
* [3 pts] - Additional Robustness
   * 1 pt - 100 MB file
   * 1 pt - Zero byte file
   * 1 pt - Code is helpful / informational when executing
