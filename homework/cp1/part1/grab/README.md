# Grab Server

This server is an implementation of the grab server for Coding Project 1 - Part 1 for CSE 30264 - Computer Networks in Fall 2026.

There are two different versions present for the server with the `server-grab.py` being the relevant server file.

| **Directory** | **Description** |
|---|---|
| `claude` | A server implemented taking the specification along with a few extra prompts via Claude code using Sonnet. |
| `stock` | A basic server implementation against which your code will be evaluated |

You are welcome to use either for your initial testing but it is important to note that your code will be graded running against the `stock` version. Both versions will be released in tandem with the Canvas assignment.
