# FAQ

* Is there a port assignment for the groups?
   * No, just pick any ports between 54000 and 54150.
* What should I connect to?
   * If you are running the server on your local machine, use the loopback adapter at `127.0.0.1`.
   * If you are running the server on the CSE student machine (where your code should eventually run), look up the IP address for the student machine via nslookup or ifconfig.
